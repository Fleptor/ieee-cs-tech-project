Detection methodology

Tier 1 statistical baseline and Tier 2 cognitive supervisor specifications

Tier 1: Mathematical Z-score profiler

< 3 μs execution

Executes in the Rust edge daemon using ndarray. Maintains a 50-sample baseline memory buffer to compute Mean (μ) and Standard Deviation (σ) across security dimensions:

Z = |X - μ| / (σ + 10⁻⁸)
  • Exfiltration ratio: Bytes out over bytes in, isolating heavy egress from download traffic.
  • Connection failure rate: Spikes in dropped frames and TCP resets indicating network scans.
  • Shannon port entropy: Identifies bindings across high-numbered dynamic ports.
  • Anomaly trigger threshold: Any metric exceeding Z > 3.0 triggers Tier 2 evaluation.

Tier 2: Cognitive LLM supervisor

Deterministic evaluation

Upon Tier 1 threshold breach, the Axum control plane dispatches asynchronous telemetry to the LLM supervisor with temperature fixed to 0.1 and strict schema enforcement: 

{
  "threat_name": "Data Exfiltration Breach",
  "confidence": 96,
  "human_explanation": "Outbound spike on unusual dynamic port",
  "should_block": true
}

When should_block = true, the control plane issues an in-kernel quarantine update to the eBPF MAC map.

Architecture documentation

Ten core design specifications for Project CIPHER

PILLAR 01
eBPF/XDP Zero-Copy Execution
Evaluates packets at the NIC driver level, dropping attacks before sk_buff memory allocation.
PILLAR 02
Split-Plane Architecture
Decouples high-speed data plane processing on the router from the cloud control plane.
PILLAR 03
8-Bit Threat Diagnostic Mask
Packs multidimensional kernel verdicts into a single byte of memory via bitwise flags.
PILLAR 04
DNS Sinkholing via Bloom Filters
O(1) time complexity mathematical Bloom Filters inside kernel memory for domain blocking.
PILLAR 05
Layer 4 Heuristic Analysis
Detection of RFC protocol violations, invalid TCP flag combinations, and legacy protocol usage.
PILLAR 06
TCP Session Tracking (Fast Path)
Bypasses deep inspection for elephant flows via LRU hash maps with statistical sampling.
PILLAR 07
Zero-Trust WebSockets & Argon2id
Memory-hard password hashing and cryptographic HTTP upgrade handshake validation.
PILLAR 08
Probabilistic Memory (HyperLogLog)
Static RAM footprint per device for cardinality estimation, immune to state exhaustion attacks.
PILLAR 09
Two-Tier Hybrid Detection Engine
Combines sub-millisecond Z-Score statistical reflexes with LLM cognitive supervisor analysis.
PILLAR 10
Fail-Open Watchdog
Hardware-level fault tolerance bypassing quarantine if user-space heartbeat stops.
